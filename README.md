# Taberoa Portfolio

Web personal de Alex Taberoa. Incluye proyectos, contacto y CV descargable en español e inglés.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Disponible en http://localhost:3302.

```sh
pnpm lint
pnpm typecheck
pnpm build
pnpm start
```

La página está en `src/app/page.tsx`, los estilos en `src/app/globals.css` y el CV en `public/alex-taberoa-cv.pdf`.

Repositorio separado de `../todo-app`; no comparte su configuración de Vercel.
