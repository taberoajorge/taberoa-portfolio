`ProjectFigure.tsx` is what the site renders (the static figure, its poster) and `Deferred.tsx` swaps in the live one after load. One folder per project: `view.ts` (sizes, projection, `PLATE`), `geometry.ts` (paths, built once), `rig.ts` (a `Rig` subclass: plan, write, reset), `options.tsx` (the figure's own controls; without `reset` they render inert in the static figure), `Figure.tsx` (the drawing and a `FigureShell`, loaded on demand). Shared code is in `engine/` and `parts/`; never import `src/site` or `src/app`. Load the `add-figure` skill before changing one.
